##Заголовок 1. Планування

Мета: створити простий застосунок “Трекер часу”, який дозволяє користувачу вимірювати час, витрачений на різні завдання, та зберігати результати.

Користувач повинен мати можливість запускати таймер для задачі, зупиняти його та бачити загальний витрачений час.

2. Аналіз вимог (User Stories)

✅ (Must have)
Як користувач, я хочу запускати таймер для конкретного завдання, щоб вимірювати витрачений час.

✅ (Must have)
Як користувач, я хочу зупиняти таймер, щоб фіксувати фактичний час роботи.

Як користувач, я хочу бачити список усіх задач із витраченим часом.

Як користувач, я хочу скидати (reset) час для задачі, щоб почати підрахунок заново.

Як користувач, я хочу видаляти задачі, щоб очищати список.

4. Реалізація (Псевдокод ключової функції — запуск таймера)
function startTimer(task):

    if task.timerIsRunning == true:
        return "Timer already running"

    task.startTime = currentTime()
    task.timerIsRunning = true
Псевдокод зупинки таймера:
function stopTimer(task):

    if task.timerIsRunning == false:
        return "Timer is not running"

    elapsed = currentTime() - task.startTime
    task.totalTime += elapsed
    task.timerIsRunning = false
5. Тестування

Запуск таймера → час починає збільшуватися.

Зупинка таймера → час фіксується і більше не змінюється.

Повторний запуск після зупинки → час додається до попереднього.

Натискання Stop без запуску → система видає повідомлення про помилку.
