1. Планування
   Мета: створити простий застосунок “Трекер часу”, який дозволяє користувачу вимірювати час, витрачений на різні завдання, та зберігати результати.
   Користувач повинен мати можливість запускати таймер для задачі, зупиняти його та бачити загальний витрачений час.
2. Аналіз вимог (User stories)
   1.Як користувач, я хочу запускати таймер для конкретного завдання, щоб вимірювати витрачений час.
   2.Як користувач, я хочу зупиняти таймер, щоб фіксувати фактичний час роботи.
   3.Як користувач, я хочу бачити список усіх задач із витраченим часом.
   4.Як користувач, я хочу скидати (reset) час для задачі, щоб почати підрахунок заново.
   5.Як користувач, я хочу видаляти задачі, щоб очищати список.

4. Реалізація
   function startTimer(task):

    if task.timerIsRunning == true:
        return "Timer already running"

    task.startTime = currentTime()
    task.timerIsRunning = true

 5. Тестування
    Запуск таймера → час починає збільшуватися.
    Зупинка таймера → час фіксується і більше не змінюється.
    Повторний запуск після зупинки → час додається до попереднього.
    Натискання Stop без запуску → система видає повідомлення про помилку.
 
 6. Висновки
    Для цього проєкту найкраще підходить Agile-модель, оскільки функціонал можна поступово розширювати (додавати статистику, графіки, категорії задач).
    Agile дозволяє тестувати продукт частинами та швидко вносити зміни на основі зворотного зв’язку.
    Waterfall буде менш гнучким, а Spiral — занадто складним для невеликого застосунку.
